# Casos (Horrores e Sucessos) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Galeria de casos do Porto (destruição urbanística, patrimonial e de verde com contestação): tema novo do mapa único + página permanente por caso, a partir de um só ficheiro por caso.

**Architecture:** Cada caso é `_casos/<slug>.md` (front matter = esquema, corpo = descrição), colecção Jekyll com permalink `/casos/:path/`. `mapa_unico.py` lê os mesmos ficheiros e escreve `mapa_unico/dados/casos.js`; `tema_casos.js` desenha os pontos e a janela (hover = cartão, clique = ficha fixa via `MU.ficha` com novo campo `corpo`). Um validador (pytest + CLI) garante esquema, concelho e citações literais. Rascunhos ficam fora do repositório público.

**Tech Stack:** Python (pyyaml, geopandas/shapely, pytest), Jekyll/GitHub Pages, Leaflet (mapa único), Playwright com Edge em `file://`.

**Spec:** `docs/superpowers/specs/2026-11-21-horrores-design.md`

## Global Constraints
- HTML gerado nunca à mão; dados embutidos, nunca `fetch()` (`file://`); fotos por `<img src>` relativo.
- Sem nomes de pessoas singulares; juízo atribuído à fonte; voz documental.
- Texto não revisto nunca no repositório público: rascunhos em `docs/horrores/rascunhos/` (gitignored).
- `lat/lon` dentro do concelho (CAOP 2025, `dtmn` `"1312"`); `freguesia` derivada, nunca escrita à mão.
- `referencias` (não `fontes`: `_layouts/default.html:10` usa `page.fontes`); `excerto` literal verificado contra `Fontes\Horrores\<slug>\<n>.txt` (fora do repositório).
- `_config.yml` `exclude` casa por prefixo: usar `"pasta/*"`; abrir o URL real antes de dar por publicado.
- Nunca fundir com os 50 Espaços; `slugify` importa-se de `espacos_pipeline.modelo`.
- Moldura só em `assets/js/moldura.js`; `test_moldura.py` guarda-a. PT-PT pré-acordo em código, comentários e commits.
- Pytest antes e depois de cada task (sem regressão); `pw_*` dos outros temas antes e depois do Task 4.
- Design: maquete aprovada pelo utilizador antes de gravar CSS/layout da página (Task 2); perguntar tamanhos.

## Review Focus
1. Ponto fora do concelho ou na fronteira → erro claro do validador, caso não entra no mapa.
2. Caso sem nenhuma foto → hover e ficha só com texto, sem `<img>` partida.
3. `excerto` com aspas/travessões tipográficos, espaços duplos ou maiúsculas diferentes da fonte → ainda verifica; excerto inventado → falha.
4. Título/descrição com `<`, `&` ou aspas → escapados na janela (a ficha usa `innerHTML`).
5. Rascunho em `docs/horrores/rascunhos/` → nunca em `casos.js`, nunca em `_site`, nunca em `git ls-files`.
(Dois casos com as mesmas coordenadas ficam ambos acessíveis: ver Task 3. Hover em ecrã táctil: Task 5.)
